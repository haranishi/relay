# 公開試験の画面設計

## 結論

招待した3人が、自分のスマホから、同じ1件の出品を、出品から受け渡し完了まで実際の API で通せる画面（`/pilot`）を足す。いまの模擬デモ（`/`）は、誰でも見られる説明として残す。画面は役ごとに分けず、1画面の中で「いま、あなたがすること」を役に合わせて1つだけ出す。

## ユーザーストーリー

| 誰が | したいこと | 受け入れの目安 |
|---|---|---|
| 出品者 | 引っ越しまでに、不要な家具を、確実に引き取る人へ渡したい | 出品は、ひな形を直すだけで出せる。応募一覧で、各人の搬出手段・手伝いの人数・メッセージが見える。第一候補と予備の選定は、画面1つで確定できる。辞退されたら、次の人に回ったことが画面で分かる |
| 受取希望者 | 条件（場所・期限・搬出）を見て応募し、選ばれたかを、画面を閉じて開き直してもすぐ知りたい | 応募は1画面で終わり、必須の入力は選ぶだけ。再読み込みしても、自分の状態（応募済み・選ばれた・繰り上がった・完了）が同じに見える |
| 選ばれた受取希望者 | 行けなくなったら、すぐ辞退して、次の人に譲りたい | 辞退は確認つきの1操作。辞退後、自分の画面は「辞退済み」になる。出品者の画面が更新される |
| 試験の参加者 | いま自分が何をすればよいかを、説明なしで5秒で知りたい。詰まったときは、次の手を知りたい | 最上部に「いま、あなたがすること」が1つだけ出る。他の人の操作待ちのときは、そう書かれ、自動で更新される。エラーは、原因と次の手を平易な文で示す |

## UXの5つの層

### 戦略

- 目的：授業の成果として、実際のクラウドでの稼働を示すこと。そして、友人3人が説明なしで最後まで通せるかを確かめること。
- 利用者：大学生。スマホ。初めて見る。
- 成功の目安：3人が、説明なしで、出品から完了まで通す。途中のエラーが、原因と次の手を示す。無料枠の内に収まる。

### 要件

- やる：招待コードでのログイン、出品（ひな形つき）、応募、第一候補・予備の選定、辞退、受け取りの確定、状況の自動更新、ログアウト、SNSへのシェアと OGP。
- やらない：画像のアップロード、メール通知、大学の認証、複数のコミュニティ、出品の編集・取り下げ、検索・絞り込み、管理画面。理由：試験の目的（通し）に要らず、無料枠と工数を食うため。

### 構造

`/`（説明と模擬デモ）から「招待コードで試す」を押すと、`/pilot` へ進む。`/pilot` は、ログイン → ワークスペースの順。ワークスペースは1画面で、上から次の並び。

1. あなたの役の表示とログアウト
2. いま、あなたがすること（主役の1枚）
3. 出品の情報
4. 進み具合（応募 → 選定 → 辞退・繰り上げ → 完了）
5. 出来事の一覧（実際の応募・受け渡しの状態から作る）

### 骨格

- スマホは縦1列。主役の1枚を最上部に置く。主要なボタンは幅いっぱいで、高さ48px以上。
- PC は、既存の2列（左に出品、右に主役の1枚と進み具合）を使う。
- 待ち・成功・失敗の知らせは、画面の同じ場所に出し、読み上げにも伝える（`aria-live`）。

### 表層

- 既存の色・角丸・影を使い、新しい配色を足さない。状態は、色だけでなく、文字と記号でも示す。
- 待っているときの動きは、`prefers-reduced-motion` で止める。

## 決めたことと、捨てた案

- **1画面で役に合わせて出す。** 3人は同じ出品を見ていて、「他の人がいま何をしたか」が分かることが大切だから。捨てた案：役別のページ。移動が増え、他の人の動きが見えなくなる。
- **模擬デモを `/` に残し、実運用は `/pilot` に分ける。** 招待のない訪問者にも説明でき、そのアクセスが API と無料枠を使わないから。捨てた案：`/` を実運用に置き換える。誰でも API を叩け、招待のない人には何も見せられない。
- **招待コードは役ごとに別。** 3人が同時に使え、役の取り違えが起きない。捨てた案：1つの合言葉と役の選択。1人が全部の役になれて、試験にならない。
- **出品はひな形つき。** 入力が増えると試験が止まるため。ひな形は編集できる。捨てた案：空の入力欄だけ。
- **更新は定期的な取得（6秒ごと）。** 画面が見えていないときは止め、長く変化がなければ間隔を延ばす。無料枠（1日10万リクエスト）を守るため。捨てた案：常時接続（WebSocket・SSE）。無料枠と工数に合わない。
- **応募者に、次の候補の名前を見せない。** 辞退の応答には、次の受取人の情報が入るが、画面には出さない。
- **画像は扱わない。** 出品のひな形はソファ1点で、絵は既存の画面と同じ描き方を使う。
